# Contributing

**English** · [Español](#cómo-contribuir) · [Português](#como-contribuir)

## The short version

This repository is a mirror: it is generated from the source and published here automatically. **Please do not open pull requests.** They cannot be merged here, and the next publish overwrites any change made in this repository, so a fix that lands here never reaches the product.

What helps is telling us. A person reads every message.

## What helps

- **A problem.** Say where you use Arroway (Claude Code, Cowork, Codex, Cursor or Gemini CLI), what you expected, and what happened instead. If an assistant showed you an error, paste it whole: the wording is what tells us where it came from. Write at [www.arroway.app/support](https://www.arroway.app/support), or [open an issue](https://github.com/oaleviola/arroway-plugin/issues/new/choose) here.
- **An idea.** Same place. Tell us what you were trying to do, not only the feature you would add: the task is what lets us tell whether the idea is the right fix.
- **A security problem.** Not a public issue. See [SECURITY.md](SECURITY.md).

## What happens next

The fix is made at the source and reaches this repository the next time the plugin is published. When a release goes out the plugin version changes, and your client picks it up through its own update path.

Everyone who writes here follows the [code of conduct](CODE_OF_CONDUCT.md).
