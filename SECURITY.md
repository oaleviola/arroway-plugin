# Security policy

**English** · [Español](#política-de-seguridad) · [Português](#política-de-segurança)

## What this repository is

This repository is the installable Arroway plugin only: the working protocol (the skill), the hooks, and the connection settings that point to Arroway's own address. It holds no server code and no credentials. It is a mirror generated from the source, so a fix is made at the source and published here.

## Reporting a security problem

Please do not open a public issue for a security problem. Write to [hello@arroway.app](mailto:hello@arroway.app) with:

- what you found and where (a file in this repository, or behavior of the Arroway service);
- the steps to reproduce it;
- what you think someone could do with it.

Reports about the Arroway service itself, not only this plugin, go to the same address. Please do not access data that is not yours while checking, and give us reasonable time to fix a problem before you describe it publicly.

For how Arroway handles security and compliance, see [www.arroway.app/en/trust](https://www.arroway.app/en/trust).
